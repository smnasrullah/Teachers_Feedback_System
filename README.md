# Teachers_Feedback_System
Teachers Feedback System is a smart academic platform that transforms student feedback into meaningful insights about teaching quality. Through structured reviews, ratings, performance analysis, and intelligent moderation, it promotes transparency, recognizes effective teaching, and supports continuous improvement in the learning environment.

## Sign-in

Every role signs in with a username and password (minimum 12 characters, lockout after repeated
wrong guesses). A forgotten password is reset with a one-time code from the Admin or the head of
department. An authenticator app (TOTP) can be required per role with one setting, for example
`TOTP_REQUIRED_ROLES=admin,hod`; see `docs/SECURITY.md`.
